PyAnsys MCP#

PyAnsys MCP is a metapackage that helps you discover and install Model Context Protocol (MCP) servers built with PyAnsys libraries. These MCPs connect large language models (LLMs) and AI tools to Ansys applications.

With these MCPs, you can:

  • Generate simulation code from natural language prompts.

  • Automate repetitive simulation tasks.

  • Get AI-assisted recommendations for simulation setup and optimization.

  • Integrate Ansys workflows into your AI-powered applications.

Each MCP follows the Model Context Protocol standard, so it works with Claude, GPT, and other MCP-compatible AI tools.

Why use MCPs?

Any AI client

Use Claude Desktop, GitHub Copilot, Cursor, or any other MCP-compatible client without additional configuration.

No custom connection code

Connect to Ansys applications without writing custom connection code. Your AI client only needs to know the tool names.

One metapackage

Install the PyAnsys MCP metapackage to access all MCPs, or install individual MCP packages as needed.

Common foundation

Use the same base library for consistent sessions, errors, and tool patterns across solvers.
