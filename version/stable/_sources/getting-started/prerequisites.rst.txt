Prerequisites
=============

Before you start, prepare the following:

- A Python environment
- A licensed Ansys software installation
- An AI agent that supports the `Model Context Protocol <https://modelcontextprotocol.io/>`_
  standard, such as Claude Desktop, GitHub Copilot, or Cursor

Download and install Ansys software
-----------------------------------

Download Ansys software from the `Ansys Download Center`_ and install it. Make sure you have a license to use it.

.. vale Google.Headings = NO

Download and install Python
---------------------------

.. vale Google.Headings = YES

Download and install the latest stable version of Python from the `Python Downloads page <https://www.python.org/downloads>`_.
